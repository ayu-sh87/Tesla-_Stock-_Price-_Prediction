# Tesla Stock Price Prediction

This project forecasts Tesla closing prices using two recurrent deep learning models:
- SimpleRNN
- LSTM

It includes:
- A live Jupyter notebook for end-to-end analysis
- A written report describing the approach
- A Streamlit app for interactive prediction and comparison

## Files
- `Tesla_Stock_Price_Prediction.ipynb` - notebook with data cleaning, EDA, GridSearchCV tuning, and model comparison
- `app.py` - Streamlit app
- `tsla_utils.py` - shared preprocessing and modeling helpers
- `report.md` - detailed project write-up
- `requirements.txt` - Python dependencies

## Dataset
Place `TSLA.csv` in the project root, or let the notebook/app download it from the provided Google Drive link automatically.

## Setup
Install the dependencies:

```bash
pip install -r requirements.txt
```

## Run the notebook
Open `Tesla_Stock_Price_Prediction.ipynb` in Jupyter or VS Code and run the cells in order.

## Run the Streamlit app

```bash
streamlit run app.py
```

## Method Summary
- Clean and sort the time series by Date.
- Handle missing values with time-aware interpolation and forward/backward fill.
- Use `Close` as the target variable.
- Create 60-day lookback sequences.
- Train and compare SimpleRNN and LSTM models for 1-day, 5-day, and 10-day horizons.
- Tune LSTM hyperparameters with GridSearchCV.

## Notes
- Stock prices are noisy and sensitive to market events, so long-horizon forecasts are naturally harder.
- LSTM generally performs better than SimpleRNN on sequential financial data because it can preserve longer memory.
- This workspace uses Keras 3 with the PyTorch backend so the SimpleRNN and LSTM models can run without TensorFlow.
