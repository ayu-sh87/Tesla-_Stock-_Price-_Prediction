# Tesla Stock Price Prediction Report

## 1. Problem Statement
The objective of this project is to build deep learning models that forecast Tesla's stock closing price using historical market data. Because stock prices are sequential, the project uses recurrent neural network approaches, specifically SimpleRNN and LSTM, and compares them across 1-day, 5-day, and 10-day forecast horizons.

## 2. Dataset and Assumptions
The dataset is expected to contain standard market fields such as Date, Open, High, Low, Close, Adj Close, and Volume.

Assumptions used in the project:
- The target variable is the closing price.
- The data is ordered chronologically by Date.
- If the CSV is not present locally, it can be downloaded from the provided Google Drive link.
- Missing values, if present, are handled with time-aware interpolation and edge filling.

## 3. Data Cleaning
Data cleaning is handled before any model training.

Key steps:
- Convert Date to a datetime type.
- Sort records by Date.
- Remove duplicated timestamps.
- Apply numeric interpolation for gaps in the time series.
- Use forward fill and backward fill for any remaining edge gaps.

Why this matters for time series:
- Mean imputation can break the temporal pattern.
- Time-aware interpolation respects continuity in the price curve.
- Forward and backward fill are used only as a fallback at the boundaries.

## 4. Exploratory Data Analysis
The notebook includes visual analysis of:
- Closing price trend over time.
- 30-day rolling mean of closing price.
- Trading volume trend.
- Correlation heatmap for numeric columns.

The purpose of EDA is to understand the trend, volatility, and relationships among the market variables before modeling.

## 5. Feature Engineering and Preprocessing
The project uses the closing price as the target series.

Preprocessing steps:
- Select the Close column as the target.
- Scale prices using MinMaxScaler.
- Convert the series into supervised learning sequences.
- Use a lookback window of past 60 trading days to predict the future value.

Forecast horizons:
- 1-day ahead prediction.
- 5-day ahead prediction.
- 10-day ahead prediction.

Sequence generation is done chronologically to avoid data leakage.

## 6. Model Development
Two neural network models are implemented:

### SimpleRNN
A simpler recurrent network used as a baseline for sequential learning.

### LSTM
A more advanced recurrent network that can retain longer dependencies in stock movement patterns.

Both models use:
- Recurrent layers for sequence learning.
- Dropout to reduce overfitting.
- Dense output layer for regression.
- Mean squared error loss.
- Adam optimizer.

## 7. Hyperparameter Optimization
GridSearchCV is used to tune the LSTM model.

Parameters tuned:
- Number of LSTM units.
- Dropout rate.
- Learning rate.

The notebook performs a grid search on the 1-day horizon and then reuses the selected values for the 5-day and 10-day comparisons.

## 8. Model Evaluation
The project evaluates models using:
- MSE: Mean Squared Error.
- RMSE: Root Mean Squared Error.
- MAE: Mean Absolute Error.
- MAPE: Mean Absolute Percentage Error.
- R2: Coefficient of determination.

It also plots actual versus predicted closing prices to visually assess how closely the models follow the real price trajectory.

## 9. Expected Findings
In stock forecasting tasks, the following pattern is common:
- LSTM usually performs better than SimpleRNN because it captures longer temporal patterns.
- Shorter horizons are generally easier to predict than longer horizons.
- Prediction error typically increases as the forecast horizon grows.
